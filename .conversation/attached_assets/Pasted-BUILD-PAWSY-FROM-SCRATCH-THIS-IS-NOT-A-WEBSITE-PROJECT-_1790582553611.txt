BUILD PAWSY FROM SCRATCH.

THIS IS NOT A WEBSITE PROJECT.

THIS IS NOT A LANDING PAGE.

THIS IS NOT A UI MOCKUP.

THIS IS NOT A PROTOTYPE WHERE BUTTONS CAN BE DECORATIVE.

THIS IS THE FIRST FUNCTIONAL VERSION OF A REAL SOCIAL APP, INITIALLY RUNNING AS A WEB APP/PWA BECAUSE THE NATIVE IOS/ANDROID APP WILL COME LATER.

The browser is simply the first distribution method.

The product itself must feel like a real mobile application.

============================================================
0. ABSOLUTE PRIORITIES

There are five non-negotiable priorities:

1. PAWSY MUST FEEL LIKE A REAL APP.
2. PAWSY MUST HAVE A DISTINCTIVE INTERACTIVE ANIMAL WORLD.
3. PAWSY MUST BE FUNCTIONAL, NOT A STATIC MOCKUP.
4. PAWSY MUST NEVER INVENT FAKE USERS OR FAKE ACTIVITY.
5. EVERY FEATURE THAT IS PRESENTED AS AVAILABLE MUST ACTUALLY WORK.

Do not sacrifice functionality for visual design.

Do not sacrifice the visual identity for generic functionality.

The goal is BOTH:

Beautiful + Functional.

============================================================

1. WHAT PAWSY IS
    ============================================================

PAWSY 🐾 is an inclusive social-discovery app.

Its purpose is to help people:

* make friends
* meet new people
* find activity partners
* find people with similar interests
* discover people nearby
* join communities
* create and join plans
* chat
* find people to explore places with
* find hobby partners
* network
* optionally date
* find someone to go outside with

The central human problem Pawsy solves is:

“I want to go somewhere or do something, but I don’t have anyone to go with.”

Pawsy should make meeting people feel natural.

The user should not feel like they are entering a dating website.

The user should feel like they are entering a social world.
